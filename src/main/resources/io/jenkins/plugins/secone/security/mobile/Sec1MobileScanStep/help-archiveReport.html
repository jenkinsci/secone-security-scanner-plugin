After a completed scan, download the executive PDF report and archive it with the build as sec1-mobile-report.pdf, so it can be opened from the build page. Off by default. The report is generated on request, which can take a few minutes. If it cannot be downloaded, the build log shows a warning and the build result is not affected.

The report is requested from the Base URL first. If the scanner nodes do not serve it, it is fetched from the Sec1 control plane, so the agent then needs to reach Sec1.
