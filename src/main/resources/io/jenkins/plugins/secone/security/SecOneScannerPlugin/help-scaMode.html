How the SCA (FOSS) scan runs.
  • API (default) - the Sec1 server clones the repository and resolves dependencies on its side. Requires the server to reach your SCM and any artifact registries.
  • SBOM upload - uploads a CycloneDX SBOM generated by your build (see SBOM File). Dependency resolution happens in your build with your own registry credentials, so this works behind private artifact registries (Nexus, Artifactory, private npm) and the server never needs SCM access. The scan responds synchronously.
