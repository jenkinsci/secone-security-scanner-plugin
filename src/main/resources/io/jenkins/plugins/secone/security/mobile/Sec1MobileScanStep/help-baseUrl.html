Sec1 Mobile Security API that receives the binary.
  • Hybrid (scanner nodes in your network): your load balancer, e.g. https://scanner.example.com/ai-sast-mobile. The binary goes to a scanner node inside your network, never to the Sec1 control plane.
  • Sec1 SaaS: leave empty.
When empty, the SEC1_MOBILE_BASE_URL environment variable is used, e.g. set once under Manage Jenkins → System → Global properties. It is separate from SEC1_INSTANCE_URL, which only applies to the SCA/SAST steps. The build log shows which value was used.
