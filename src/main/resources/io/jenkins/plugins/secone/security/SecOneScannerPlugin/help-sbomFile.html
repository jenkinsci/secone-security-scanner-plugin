Path to a CycloneDX SBOM (JSON), relative to the workspace. Used only when SCA Mode is SBOM upload. Generate it earlier in the build, e.g.: 
mvn org.cyclonedx:cyclonedx-maven-plugin:makeAggregateBom -DoutputFormat=json
which produces target/bom.json. For npm use npx @cyclonedx/cyclonedx-npm, for Gradle the org.cyclonedx.bom plugin.
