Sec1 CLI installation used when SCA Mode is SBOM upload and no SBOM File is given. The CLI is auto-downloaded to the agent (Manage Jenkins > Tools > Sec1 CLI), generates a CycloneDX SBOM via cdxgen (all ecosystems — Sec1's standard generator), falling back to the Maven/npm/Gradle CycloneDX tooling, using the agent's own toolchain and registry credentials, and uploads it for scanning. If an SBOM File is configured instead, the plugin uploads that file directly and this installation is not used.
